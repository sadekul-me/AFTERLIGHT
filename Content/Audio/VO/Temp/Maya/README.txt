Drop 16-bit PCM WAV files here. Filenames must match the VoiceId in docs/audio/temp-vo-manifest.md.

Examples: Call.wav  Fingers.wav  Name.wav  LongWay.wav  Move.wav  FollowEli.wav  QuestionLine.wav  Posts.wav  Stay.wav  Dry.wav  Drip.wav  Tonight.wav  Sorry.wav  Tick.wav  Pump.wav  Pipe.wav  Sure.wav  No.wav  Four.wav  Down.wav  Okay.wav  DontTin.wav  EliTin.wav

No editor import is required. Standalone play loads these files from disk.
If a file is missing, the slice stays on subtitle-only timing.
