Drop 16-bit PCM WAV files here. Filenames must match the VoiceId in docs/audio/temp-vo-manifest.md.

Examples: Specific.wav  Dead.wav  Where.wav  Yours.wav  Hands.wav  Did.wav  Was.wav  W1.wav  W2.wav  W3.wav  W4.wav  W5.wav

No editor import is required. Standalone play loads these files from disk.
If a file is missing, the slice stays on subtitle-only timing.
